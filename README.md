# Adding Annotations to Blazor Maps

## Overview

This sample demonstrates how to use the Syncfusion [Blazor Maps](https://www.syncfusion.com/blazor-components/blazor-map) component to add annotations in a hosted Blazor WebAssembly application. The implementation shows how custom annotation content can be displayed on top of a map layer to highlight important information, identify regions of interest, and enrich map-based visualizations. By combining map rendering with annotation elements, developers can create more informative geographic applications that provide additional context directly within the map surface.

## Key Features

- Demonstrates annotation rendering within the Syncfusion Maps component.
- Shows how custom annotation content can be displayed over map layers.
- Demonstrates positioning annotation elements on specific map locations.
- Illustrates how annotations can be used to present contextual geographic information.
- Uses the sample implementation hosted in `Client/Pages/Index.razor`.
- Demonstrates map visualization enhanced with annotation overlays.
- Shows how annotation content can be integrated into a Blazor WebAssembly Maps application.
- Supports displaying custom UI elements as annotation content.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file:

   `AddingAnnotation.sln`

3. Restore NuGet packages.
4. Set the startup project
5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root folder.

```bash
dotnet restore
dotnet run
```
